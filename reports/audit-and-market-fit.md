# Portfolio gap and Finland market-fit audit

## Existing evidence audited first

The public `applied-ai-lab`, `portfolio` and profile README already provide convincing evidence for:

- official-source acquisition, analytical contracts and public interfaces;
- RAG/retrieval, bounded agents, evaluation gates, grounding and prompt-injection boundaries;
- PySpark/Delta Bronze–Silver–Gold, incremental orchestration, data quality and governance;
- tabular feature engineering, chronological validation, model comparison/calibration and server parity;
- Docker, CI and deployment patterns.

Repeating another RAG system, lakehouse or sklearn classifier would add little signal.

## New capability class added

This repository adds inspectable evidence not previously present: tensors, explicit PyTorch forward/backward training, Dataset/DataLoader, CNN and modern context segmentation, remote-sensing bands, raster COG reads, CRS/resampling/alignment, spatial holdout/leakage tests, paired mask augmentation, mIoU/per-class segmentation evaluation, pixel/patch error visuals, ECE/reliability/risk-coverage, MLflow run artifacts, versioned neural checkpoints and georeferenced imagery inference.

## Current Finland-oriented relevance check

This design was checked against several current requirements, not copied from one posting:

- A current [Metsäavain Geospatial AI Developer](https://laura.fi/en/vacancies/metsaavain-oy/geospatial-ai-developer/3845725/) role emphasizes AI/ML solutions using remote sensing, GIS and forestry data plus robust analytical code.
- A current [Kuva Space Data Scientist](https://careers.kuvaspace.com/jobs/7813263-data-scientist) role asks for Python engineering, hands-on ML, remote-sensing imagery, GDAL/Rasterio-style tooling, projections, georeferencing and raster/vector data.
- A current [University of Turku Geospatial AI](https://ats.talentadore.com/apply/1-2-tutkijatohtorin-tai-vaitoskirjatutkijan-tehtavaa-geospatiaalisen-ja-selitettavan-tekoalyn-ja-koneoppimisen-parissa-laajamittaisessa-ymparistomalli/ZY5bMY?lang=en) opening calls out spatial modelling of Sentinel-1/2, Landsat, drone imagery or LiDAR and multi-modal remote-sensing data.
- Kuva Space's [Geospatial AI leadership role](https://careers.kuvaspace.com/jobs/8071902-director-of-geospatial-ai) describes the broader intersection of ML, computer vision, remote sensing, scientific computing and turning satellite data into operational products.

The resulting signal is intentionally narrow and evidence-backed: the candidate has actually built, trained, selected, evaluated, debugged and served a deep-learning segmentation model on Finnish geospatial imagery. The project does not add unrelated orchestration or LLM technology merely because it appears in other roles.
